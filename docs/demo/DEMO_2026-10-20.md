## Chạy trên máy Windows

Cần PHP 8.2+ có pdo_sqlite, Composer, Node 22 và npm trong PATH.
Trong repo đã checkout nhánh demo, chạy lần lượt:

```powershell
composer install
npm ci
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-progress-demo.ps1
```

Script hỏi mật khẩu demo, không lưu mật khẩu vào Git. Truy cập
http://127.0.0.1:8020. Nếu bận cổng, thêm `-Port 8021` và dùng URL mới.
Tài khoản seed: `admin@example.test`, `sales1@example.test`,
`sales2@example.test`, `customer1@example.test` đến `customer3@example.test`;
dùng mật khẩu vừa nhập khi khởi tạo lần đầu. Seed lại KHÔNG đổi mật khẩu hoặc
mở khóa tài khoản đã tồn tại. Tài khoản thử thêm khi diễn tập chỉ có trên máy diễn tập.

Script dùng RIÊNG `database/demo-progress-20261020.sqlite` (Git bỏ qua);
không sửa .env, không xóa/reset database khác. APP_KEY mới mỗi lần khởi chạy
làm hết hiệu lực phiên demo cũ. Ctrl+C để dừng; khởi động lại rồi đăng nhập lại.
Có thể chạy lại script để giữ dữ liệu và kiểm tra migrate/seed lặp.
Không chạy migrate:fresh để sửa lỗi.

Đây là phương án diễn tập SQLite, không phải bằng chứng đã nghiệm thu MySQL.
Môi trường đích của môn học vẫn MySQL 8. Muốn demo MySQL thì cần chuẩn bị DB riêng
và kiểm lại theo SETUP; không đổi DB ngay trước buổi trình bày.
